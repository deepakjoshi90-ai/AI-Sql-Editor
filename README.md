# AI SQL Query Auditor

## Project Overview
AI SQL Query Auditor is a Python application built with Streamlit and MySQL that allows users to enter SQL queries and execute them against a database.

## Features
- Enter SQL queries through a web interface.
- Execute queries against a MySQL database.
- Display query results in a table.
- Show query execution errors.

## Technologies Used
- Python
- MySQL
- Streamlit
- VS Code

## How to Run
1. Install the required dependencies:
   `pip install -r requirements.txt`
2. Configure your MySQL connection using environment variables.
3. Create the required database and tables.
4. Start the application:
   `python -m streamlit run app.py`

## Security
Never commit database passwords, API keys, or other credentials to the repository.
